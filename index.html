  • Zero double-counted money

    When modules talk, a retry could book the same payment twice. I made every message safe to repeat, and the ledger passed internal audit.

    ▸Under the hood
    RabbitMQidempotent consumersdead-letter queues

    The server kept choking. I traced it to a giant log table no one had indexed, fixed it, and the spikes stopped.

    The same data was fetched again and again. Now the system remembers it, for all 500+ users.
